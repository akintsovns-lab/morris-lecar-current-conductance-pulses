# Пороговая динамика нейрона Морриса–Лекара при токовом и кондуктансном импульсных входах

Код и рисунки к статье «Пороговая динамика нейрона Морриса–Лекара при токовом и кондуктансном
импульсных входах» (журнал «Известия вузов. Радиофизика»). Репозиторий воспроизводит рис. 1–3
и таблицу порогов статьи.

> Ссылка на статью: *[указать после публикации]*

## Что внутри

| Файл | Назначение |
|---|---|
| `ml_figures.py` | расчёт модели, порогов, бифуркаций и построение рисунков |
| `ml_checks.py` | контрольные расчёты: шаг интегрирования, время наблюдения, сетка по G, гистерезис, длинные импульсы (τ до 800 мс) |
| `requirements.txt` | зависимости Python |
| `output/fig1.pdf`, `fig2.pdf`, `fig3.pdf` | рисунки статьи, вектор, ширина 160 мм |
| `output/fig1.png`, `fig2.png`, `fig3.png` | те же рисунки, 600 dpi |
| `output/thresholds_ML.csv` | пороги `A_th`, `G_th`; `G_up_main` — верхняя граница основного спайкового окна (бисекция), `G_up_last` — край последнего спайкового интервала на сетке (отличается от `G_up_main` при τ = 60, 100 мс в классе I, где область спайка состоит из двух интервалов) |
| `output/run.log`, `output/checks.log`, `output/checks_ML.csv` | вывод скриптов и результаты контрольных расчётов |

## Запуск

```bash
pip install -r requirements.txt
python ml_figures.py             # полный расчёт, около 1–2 мин, пишет файлы в output/
python ml_figures.py --replot    # только перерисовать рисунки из output/cache.npz
python ml_checks.py              # контрольные расчёты (около 2–3 мин, после ml_figures.py)
```

Проверено на Python 3.12 (numpy, scipy, matplotlib 3.10+, pandas).

## Модель и метод (кратко)

* Двумерная модель Морриса–Лекара, два набора параметров: класс I (седло-узел на инвариантной
  окружности: `gCa = 4.0`, `V3 = 12`, `V4 = 17.4`, `phi = 0.067`) и класс II (субкритический Хопф:
  `gCa = 4.4`, `V3 = 2`, `V4 = 30`, `phi = 0.04`); остальные параметры общие (см. таблицу 1 статьи).
* Стимулы: токовый импульс `I = A` и кондуктансный импульс `I = G (V_rev − V)`, `V_rev = 0 мВ`,
  длительность `tau = 0.7…100 мс`.
* Интегратор: Рунге–Кутта 4-го порядка, фиксированный шаг `dt = 0.1 мс`, векторизован по набору амплитуд.
* Критерий спайка: `V_max > +20 мВ`. Порог: скан по логарифмической сетке (100 точек) и бисекция (22 шага); верхняя граница основного спайкового окна — также бисекцией между узлами сетки.
* Единицы: `V` — мВ, `t` — мс, `I` — мкА/см², `G` — мСм/см², `C` — мкФ/см².

## Формат рисунков

Требования журнала: вектор (PDF, шрифты встроены), ширина 160 мм, растр не хуже 300 dpi (PNG 600 dpi), без координатной
сетки, физические величины на осях обозначены буквами с единицами («V, мВ», «τ, мс»).
